# Tamil Nadu HR&CE Portal

Next.js prototype for the Tamil Nadu Hindu Religious & Charitable Endowments Department.

- **Live:** https://tn-hrce.vercel.app
- **Stack:** Next.js 15 · React 19 · Tailwind CSS · TypeScript
- **Languages:** English + Tamil (via `lib/i18n.ts`)

## Local development

```bash
npm install
npm run dev        # http://localhost:3000
```

## Deploy

Push to `main` — Vercel auto-deploys.
